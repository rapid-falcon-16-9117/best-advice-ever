One sentence, 140 characters, about the best advice ever received. Grandma, 82, sold her wedding ring for a college deposit and said: "Never let a man, or a job, make you small enough to fit in his pocket." The program in `main.py` writes that line to `entry.txt` in the output directory. It is a two-beat micro-story: a concrete, dated sacrifice, then the advice it earned, landing on a final image rather than a moral.

## Run it

```sh
python3 main.py
```
